## Overview
Party Prep Tracker App is simple android app that store party supplies, allowing users to categorize them(e.g, snacks, decorations, drinks), and provide detailed views of their shopping lists.

##Features
-Splash screen that display the the name of the app for 3 seconds of duration;
- main screen where the user will be asked to put the item's name, category and quantity;
- the main screen contain the purple and gold as festive scheme to match the theme
-  instant feedback after each action in the app;
-  buttons that allow the user to proceed and also return to the main page or screen.

## App structure
-UI: Activities (Screens);
-Model: Data class().

##Technologies used
-Kotlin;
-Android Studio;
-XML layouts;
-Android SDK.

##App Flow
1.**SplashScreen**
-displays the name of the app for # seconds of duration
2.**MainActivitie**
-Displays the items;
-navigate to detailed view screen.
3.**DetailedViewScreen**
-display a list of all items with their specific details:name, category, quantity, and comments;
-contain a button that allows the user to go back to main screen or MainActivity.
